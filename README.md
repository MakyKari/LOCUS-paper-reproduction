# LOCUS paper reproduction

Reproduction of *LOCUS: Low-Dimensional Model Embeddings for Efficient Model Exploration, Comparison, and Selection* (arXiv:2601.21082) with the authors' code ([patel-shivam/locus_code_release](https://github.com/patel-shivam/locus_code_release)).

- `REPORT.pdf`, `REPORT_EN.md` — the report.
- `repro/` — our scripts: baselines, experiments, run launchers, tests.
- `results/` — tables, figures and summaries of every stage.
- `runs/` — training runs (checkpoints, logs, metrics) and the run registry.

Figures and values marked as the paper's (`results/paper/`) are taken unchanged from arXiv:2601.21082 by Patel et al., licensed under [CC BY-NC-ND 4.0](https://creativecommons.org/licenses/by-nc-nd/4.0/).
